Single Instruction Debugger

Spring 2025

NYCU — Advanced Programming in the UNIX Environment

  • Designed an address-keyed breakpoint table — supporting multiple breakpoint IDs on the same instruction — around a deferred-restore model: a hit breakpoint's original byte is written back only right before the next resume, not immediately. This replaced an earlier eager-restore design that could not reliably resume execution through jump-type instructions once a breakpoint was involved. Redesigning breakpoint recovery →
  • Built the command-dispatch loop around a three-way return protocol, letting a single outer loop distinguish commands that already consumed a waitpid() call from ones that still need one — keeping single-step, continue, and syscall-tracing state consistent across breakpoint hits.
  • Resolved the true entry point and load base of PIE and dynamically linked binaries via /proc/[pid]/auxv and /proc/[pid]/exe, so offset-based breakpoints (breakrva) stay correct despite ASLR.
