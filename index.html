Single Instruction Debugger

Spring 2025

NYCU — Advanced Programming in the UNIX Environment

  • Designed an address-keyed breakpoint table — supporting multiple breakpoint IDs on the same instruction — around a deferred-restore model: a hit breakpoint's original byte is written back only right before the next resume, not immediately. This replaced an earlier eager-restore design that could not reliably resume execution through jump-type instructions once a breakpoint was involved.
  • Built the command-dispatch loop around a three-way return protocol, letting a single outer loop distinguish commands that already consumed a waitpid() call from ones that still need one — keeping single-step, continue, and syscall-tracing state consistent across breakpoint hits.
  • Resolved the true entry point and load base of PIE and dynamically linked binaries via /proc/[pid]/auxv and /proc/[pid]/exe, so offset-based breakpoints (breakrva) stay correct despite ASLR.

Remote Working Ground Server

Spring 2025

NYCU — Network Programming

  • Implemented a multi-client shell server two different ways: a single process multiplexing every client with select(), and a process-per-client design that coordinates shared state through POSIX shared memory and signals instead of one address space.
  • The select() design serves up to 40 clients from one process by dup2-ing its stdin/stdout/stderr onto whichever client socket has a line ready, then restoring them before the next cycle.
  • Built a second server around one process per client, keeping the connection table, broadcast buffer, and inter-user pipe status in POSIX shared memory, coordinated by SIGUSR1/SIGUSR2 signals across processes.
  • Built the underlying shell's command-pipeline engine (ordinary and numbered pipes |N, redirection, and background execution), reused unmodified as the per-connection interpreter in both server designs.

AES Linux Kernel Module

Spring 2025

NYCU — Advanced Programming in the UNIX Environment

  • Designed a per-file-descriptor AES-ECB crypto device (/dev/cryptodev) with independent encryption state per fd, including PKCS#7 padding/unpadding with strict validation against malformed ciphertext at finalize.
  • Exposed live telemetry (byte counters, 256-entry byte-frequency histogram) through /proc/cryptomod; the shared counters are guarded by a global mutex and each fd's own buffer/state by a per-fd mutex, keeping both concurrent opens and concurrent syscalls on the same fd race-free.
  • Root-caused a double-free inherited from course-provided sample code by capturing SLUB debug logs (slub_debug=FZUP) under QEMU; it corrupted data across unrelated processes under concurrent load.
