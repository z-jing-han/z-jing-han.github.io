Single Instruction Debugger

Spring 2025

NYCU, Advanced Programming in the UNIX Environment

  • Rewrote breakpoint handling after finding that the first design did not handle breakpoints on jump instructions: the original byte is now restored, single-stepped and re-inserted only when the target resumes.
  • Breakpoints are stored by address, so several IDs can share one instruction; command handlers return one of three states so the main loop never calls waitpid() twice.
  • Supports PIE and dynamically linked binaries by reading AT_ENTRY from /proc/[pid]/auxv and the load base from /proc/[pid]/maps.

Remote Working Ground Server

Spring 2025

NYCU, Network Programming

  • Implemented one multi-user shell service with two concurrency models: a single select() process that swaps stdio and environment per client (up to 40 clients), and a fork-per-client server.
  • In the multi-process version, the user table, message buffer and user-pipe state live in POSIX shared memory; SIGUSR1/SIGUSR2 notify other processes, and user pipes are named FIFOs.
  • The shell supports numbered pipes (|N, !N), redirection, user pipes (>N, <N) and chat and firewall commands.
